How implied value is computed

One function scores every row. No protocol name is special-cased, and no row is hand-picked. Growth and age are not fitted into the value: growth enters only as a bounded carry, a stated projection, and age enters only through the token odds.

Note to the judge

1. Working radar: buildBoard ranks … of … watchlist protocols plus … more; every row is checked against board.json — checksum …, FNV-1a of rank:slug:implied.

2. Value model: impliedValue uses TVL, category, 7-day change and age with no token, never a name; fitValueTwoStage fits the size curve on the live comps, valueEvidence tests it leave-one-out (×…) and walk-forward (×…).

3. Token odds: fitOddsLogistic fits the logistic on the shape-passing peers, everOdds turns it into ever-odds by a life table; oddsEvidence gives walk-forward Brier … against a … base.

4. Farm plans: farmSteps sets the steps from each row's category and chains, with cost, time and the exitDrop exit rule; netFor prices every row on the depositFor deposit. FARM means verdictFor passes: ever-odds ≥ 50%, net > 0 and ≥ $20/hour.

5. Page: sortHead, renderBoard and openDetail; state lives in the URL hash. Click a column to sort, a row for its full plan.

Limits: the value model misses by ×… leave-one-out; the odds ceiling is the snapshot's oldest cohort, … years. logit p(age) = -1.169 + 0.715 x years + 0.258 x ln(TVL/$100M) - 2.326 x 7d growth - 0.140 x family
  fitted by fitOddsLogistic on the shape-passing peers
  442 shape-passing peers: 244 record a symbol; 242 own it (2 inherit a sibling's)
ever-odds = (p(5.07y) - p(age)) / (1 - p(age))  — among peers still tokenless at this age,
  the share that ever record one by the ceiling, the snapshot's oldest cohort
12-month odds = (p(age + 1y) - p(age)) / (1 - p(age))
implied = if it launches x growth carry x ever-odds
net on a deposit = implied x drop share x (deposit / TVL) - gas - deposit x 4% x (hold / 365)
FARM = ever-odds ≥ 50% and net > 0 and net/hour ≥ $20 on the row's deposit

Out-of-sample evidence

Each term is kept only if it lowers the held-out miss on both tests: leave-one-out on the live-token protocols with a positive market cap, and walk-forward (older-listed protocols predict newer-listed ones). The flat median multiple is the baseline. Growth and age were tested in the value model and dropped — neither helped on both tests. The family effect lives in the odds, not the value: only 2 live comps are family children, so it cannot move the value fit.
