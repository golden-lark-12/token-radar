How implied value is computed

One set of functions scores every row: fitValueTwoStage, computeImpliedValue, estimateTokenOdds, buildFarmPlan, verdictFor, verifyWatchlist. The board ranks 40 of 40 watchlist protocols plus 158 more; checksum 63fdb827, FNV-1a of rank:slug:implied. The value model misses by ×3.39 leave-one-out; the held-out miss is leave-one-out (×3.39) and walk-forward (×2.96).

if it launches = exp(6.9646 + 0.5223 x ln(TVL) + category_effect)
growth carry = 1 + 0.01 x clip(change_7d, -25%, +25%)  — a stated projection, not a fit
logit p(age) = -1.169 + 0.715 x years + 0.258 x ln(TVL/$100M) - 2.326 x 7d growth - 0.140 x family
  fitted on the shape-passing peers
  442 shape-passing peers: 244 record a symbol; 242 own it (2 inherit a sibling's)
ever-odds = (p(5.07y) - p(age)) / (1 - p(age))  — among peers still tokenless at this age,
  the share that ever record one by the ceiling, the snapshot's oldest cohort, 5.07 years
12-month odds = (p(age + 1y) - p(age)) / (1 - p(age))
implied = if it launches x growth carry x ever-odds
net on a deposit = implied x drop share x (deposit / TVL) - gas - deposit x 4% x (hold / 365)
FARM = ever-odds ≥ 50% and net > 0 and net/hour ≥ $20 on the row's deposit
SKIP = net ≤ 0, or break-even odds above the cap, or ever-odds < 30%, or fees above the slice
