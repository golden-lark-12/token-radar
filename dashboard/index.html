Each protocol is scored from its own snapshot figures. The value if a token launches is a power law in TVL fitted to the live-token comparables — market cap grows sub-linearly with TVL, so a flat multiple over-values the largest protocols by up to 9× — adjusted for seven-day growth and age. Token odds come from a logistic fit on all 758 protocols: age is the signal, not the category. Implied value is a model, not a promise — it ranks, it does not price.

How implied value is computed

One function scores every row. No protocol name is special-cased, and no row is hand-picked. The coefficients are fitted on the snapshot's live-token protocols, not assumed.

if it launches = exp(8.9076 + 0.4649 x ln(TVL) - 2.8915 x growth/100 - 0.1769 x ln(age_days)) token odds = 1 / (1 + exp(3.771 - 0.045 x ln(TVL) - 0.51 x ln(age_days))), clipped 0.05–0.95 implied = if it launches x token odds net on $1,000 = implied x 10% x ($1,000 / TVL) - gas

Out-of-sample evidence

Each term is kept only if it lowers the held-out miss in both tests: leave-one-out and walk-forward (fit on the older half of the live tokens, predict the newer half). A flat median multiple is the baseline. A term that does not help in both tests is not used.
