Integrity: checking the table against its own arithmetic…

Each protocol is scored from its own snapshot figures. The value if a token launches is a size curve in TVL fitted to the live-token comparables, plus a category effect — growth and age are deliberately NOT in the value: a crasher and a grower with the same TVL and category get the same value. Token odds come from a logistic fit on all 758 protocols: age, size and growth decide how likely a token is, not how big it would be. The verdict is odds-based — farm at 50% or better. The net is information, not the verdict: on a $1,000 ticket most slices are small next to gas, so use the what-if controls to see what pays at your size. Implied value is a model, not a promise — it ranks, it does not price.

How implied value is computed

One function scores every row. No protocol name is special-cased, and no row is hand-picked. Growth and age are NOT in the value model: they help predict WHICH protocols record a token, so they enter through the odds, never through the value.

if it launches = exp(6.9646 + 0.5223 x ln(TVL) + category_effect) token odds = logistic(0.1959 + 0.1682 x z(ln TVL) + 0.4281 x z(ln age, floored 365d) - 0.2668 x z(growth)), clipped 0.05–0.95 implied = if it launches x token odds net on a ticket = implied x drop share x (ticket / TVL) - gas - ticket x 4% x (hold / 365)
