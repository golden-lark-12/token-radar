Each protocol is scored from its own snapshot figures: TVL times a multiple fitted to live-token comparables in its category, adjusted for seven-day growth and the odds it ever launches a token. The fit was validated on a held-out split of live tokens. Implied value is a model, not a promise — it ranks, it does not price.

How implied value is computed

One function scores every row. No protocol name is special-cased, and no row is hand-picked. Age is not in the formula: it shows no trend in the multiple, so the maturity factor is flat at 1.0.

implied = TVL x fitted_multiple(category) x growth x token_odds growth = 1 + 0.01 x clip(change_7d, -30, +30) token_odds = clip(category token rate x TVL-band ratio x age-band ratio, 0.05, 0.95)

Fitted multiples by category

Fitted mcap / TVL multiples, shrunk toward the global positive median 0.214 and capped at 2.0. Categories with no live comparables use 0.214.

Held-out validation

Held-out validation on the 144 market-cap-live protocols, 80/20 split, 5 seeds — median absolute percentage error 90–125% (seed 42: 98.8%). The category fit barely beats the overall-median baseline (MedAPE 87–99%). This model ranks, it does not price — implied values are order-of-magnitude scores with ~2x typical error.
